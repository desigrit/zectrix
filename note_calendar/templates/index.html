    Automatic updates need a Google Desktop OAuth client. Calendar access is read-only.

    1. In Google Cloud, enable the Calendar API and configure the consent screen.
    2. Create an OAuth client for a Desktop app, then download its JSON file.
    3. Choose the file below and connect the account that can read your calendar.
